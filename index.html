Membaca bahasa parabola.

Fungsi kuadrat menggambarkan hubungan yang grafiknya berbentuk parabola.

01 / Bentuk umum

y = ax² + bx + c

a, b, dan c adalah bilangan real; a tidak boleh 0. x adalah masukan, sedangkan y adalah nilai fungsi.

02 / Arah dan lebar

Jika a positif, parabola membuka ke atas dan memiliki nilai minimum. Jika a negatif, membuka ke bawah dan memiliki nilai maksimum. Semakin besar |a|, semakin ramping grafiknya.

03 / Sumbu dan puncak

Sumbu simetri adalah garis x = −b/(2a). Titik puncaknya (−b/(2a), f(−b/(2a))). Titik ini merupakan posisi terendah atau tertinggi parabola.

04 / Titik potong

Saat x = 0, grafik memotong sumbu-y di (0, c). Titik potong sumbu-x diperoleh dari ax² + bx + c = 0. Diskriminan D = b² − 4ac menentukan jumlahnya: D > 0 dua titik, D = 0 satu titik, D < 0 tidak ada.

05 / Contoh: y = x² − 4x + 3

a = 1, b = −4, c = 3. Grafik membuka ke atas. Sumbu simetri x = 2, titik puncak (2, −1), titik potong sumbu-y (0, 3), dan titik potong sumbu-x (1, 0) serta (3, 0). Plot titik-titik tersebut, cerminkan terhadap x = 2, lalu hubungkan menjadi kurva halus.

Ilustrasi: puncak (2, −1) berada di tengah kedua titik potong sumbu-x.
